# api

Python scripts that query the JSONPlaceholder REST API for employee TODO data.

- `0-gather_data_from_an_API.py <id>`: prints TODO progress
- `1-export_to_CSV.py <id>`: writes `<id>.csv`
- `2-export_to_JSON.py <id>`: writes `<id>.json`
- `3-dictionary_of_list_of_dictionaries.py`: writes `todo_all_employees.json`
